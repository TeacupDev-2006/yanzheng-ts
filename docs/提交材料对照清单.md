## 三、唯一阻塞项的解锁路径（AGH daemon 闭环）

阻塞：Windows 下 AGH daemon 文件锁强制要求 MSVC 编译的原生模块（源码级强制，无开关）。

| 路径 | 步骤 | 耗时 |
|---|---|---|
| A（若 UAC 弹窗仍在） | 点"是"完成 Build Tools 安装 → `pnpm --filter @agnes/system-node build:native` → `pnpm --filter @agnes/cli build:local` → `node scripts/agh-e2e.mjs` | ~10 分钟安装 |
| B | 管理员 PowerShell 重跑 winget 安装 BuildTools（命令见 docs/AGH接入状态.md） | ~10 分钟 |
| C（零编译） | `wsl --install` 后在 WSL 内克隆 agnes-harness 并跑同一闭环脚本（POSIX 锁为纯文件实现） | ~30 分钟 |

闭环脚本自动完成：装插件 → 连续执行 thesis_gate→sections→review（≥3 步）→ 导出 AGH 执行记录（JSONL/HTML）到 docs/——**直接产出第七节要求的证据**。拿到赛事 Agnes key 后，把 `YANZHENG_LLM_BASE_URL/MODEL_*` 指向 Agnes 端点再跑，合规等级最高。
