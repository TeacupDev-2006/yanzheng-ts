# 演示视频剧本：《给 AI 评卷装上制度与底座》（4 分 30 秒，含 AGH 对比）

> 对比原则：只展示真实操作，不贬低任何一方——裸 LLM 的意见并非没用，而是**不可验证**；
> 手动编排并非不能用，而是**没有编排、审批与留痕**。差异说完即止，结论交给观众。

## 第二幕 · 对比一：裸 LLM vs 研证（0:25–1:40）【同样一篇论文，两种可信度】

### 镜头 2-1（窗口 1，约 35 秒）
操作：在大模型聊天网页粘贴论文摘要 + 提问"请评审这篇本科毕业论文的质量"
等待回答出现后滚动展示

> **旁白**：
> "先看常见做法——直接问一个大模型。它确实给出了意见：有优点、有不足。
> 但请注意三个问题：**分数从哪来？** 每次刷新分数都在变；
> **证据在哪？** 说'创新性不足'，却没有定位到章节和文献；
> **过程在哪？** 关了网页，什么都没留下。"

### 镜头 2-2（窗口 2，约 40 秒）
操作：切到研证投稿页 → 上传**同一篇论文** → 送审 → 等待（倍速）→ 报告从上往下滚

> **旁白**：
> "同一篇论文，交给研证：13 位 AI 评卷员分四团**互盲**打分——互相看不到彼此的分数；
> 每个扣分点都**定位到章节**、附修改建议；引用逐条到 Crossref 验真、查重有分块比对证据；
> 团内分差超过 15%，自动触发更强的仲裁模型复核；
> 页脚记录了每一次模型调用的 token 成本。
> 分数怎么来的、证据是什么、花了多少——全部可查。"

## 第三幕 · 对比二：无 AGH 手动编排 vs AGH 自主编排（1:40–3:40）【AGH 增量价值】

### 镜头 3-1（窗口 4，约 40 秒）——无 AGH：开发者手动串联
操作：VS Code 展示 `manual-steps.mjs`（10 行代码：手动 import 三个函数、手动传参、按顺序调用）→ 运行 → 输出结果

> **旁白**：
> "研证有三个评卷能力：硬性门检、章节切分、全流程评卷。没有底座的话，
> 就像现在这样：开发者写代码手动调用、手动传参、自己决定先做什么后做什么。
> 能跑——但每换一个使用方就要重写一遍编排；没有权限审批；更没有执行留痕。"

### 镜头 3-2（窗口 3，约 55 秒）——AGH：一次指令，自主编排
操作：CMD 运行 `scripts\run-agh-e2e.cmd` → 滚动展示：
① 插件 `actual=running trusted=true`
② `① thesis_gate 经 daemon 真实执行`（word_count=1267）
③ `② thesis_sections 经 daemon 真实执行`
④ `权限审批请求: thesis_review paperPath=...`（**停 2 秒**）
⑤ `③ thesis_review … report_id=… score=71`
⑥ `执行记录导出 — AGH执行记录.jsonl（84 行）`

> **旁白**：
> "接入 Agnes Harness 之后，同样这三个能力变成了 AGH 里的注册工具。
> 一条指令，AI 助手**自主规划**完成了全部流程：先硬性门检——字数与金标逐字一致；
> 再章节切分；到最关键的评卷步骤，AGH 弹出**权限审批**——写文件、调模型的动作必须经人批准；
> 批准后真实执行，报告落盘。最后 AGH 导出原生执行记录：84 行工具调用事件，
> 每一次调用、每一个参数、每一次审批，全部留痕、可人工核查。
> **编排交给智能体，制度交给底座**——这就是 AGH 的价值。"

## 附录 A：manual-steps.mjs（镜头 3-1 用，真实可跑，已验证）

文件位于 `scripts\manual-steps.mjs`，录制时 CMD 运行 `node scripts\manual-steps.mjs`
（③ 完整评卷需先 `set "YANZHENG_API_KEY=..."`，约 7 分钟；录制可临时注释第 ③ 段只演 ①②）。

```js
// 无 AGH：开发者手动编排三个能力（节选，完整文件见 scripts/manual-steps.mjs）
import { runGate, splitSections, reviewPaper } from '../packages/core/dist/index.js'
const text = await readFile('testdata/demo_paper.txt', 'utf8')
console.log('① 手动门检（人工传参）:', runGate({ text, minWords: 1000 }))
console.log('② 手动切分:', splitSections(text).length, '个章节')
const report = await reviewPaper({ text, minWords: 1000 })
console.log('③ 总分:', report.finalScore, '——无审批、无执行留痕')
```

## 附录 B：翻车点与保险

- 窗口 2 必须是**真实模式**（配置过 key），否则徽标会露馅；录制前 `curl http://127.0.0.1:8600/health` 确认 `"mode":"real"`
- 大模型网页的回答每次不同——**提前生成一次**满意的回答，录制时重新提问并快进等待
- AGH 段若 daemon 未起：先跑一次 `scripts\run-agh-e2e.cmd` 确认全绿，再正式录
- CMD 字体调大；`run-agh-e2e.cmd` 输出滚动快，可录两次后期剪辑关键行
- 全片不要出现任何 API Key（终端里 set 的变量值、配置文件内容都避开）
