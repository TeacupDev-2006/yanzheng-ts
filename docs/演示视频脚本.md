# 演示视频拍摄脚本（3~5 分钟，照着念即可）

> 官方要求：以实际操作为主，展示①任务输入 ②执行过程 ③外部能力调用 ④反馈调整 ⑤结果验证 ⑥异常处理。
> 本脚本总时长约 4 分钟，六个要素全覆盖，每段标注了对应关系。

## 一、录制前准备（10 分钟）

1. **起服务**（CMD，保持窗口开着）：
   ```bat
   cd /d D:\ZCode\2026年江苏省AI+科学与工程创新实践黑客松 TS重构
   set "DEEPSEEK_API_KEY=你的key"
   pnpm web
   ```
   （真实模式演示更有说服力；不想花 key 就不加 set，页面会显示"演示模式"徽标，同样完整）
2. **备好文件**：testdata\paper_good.md（合格）、testdata\paper_poor.md（不合格，打回用）
3. **浏览器准备**：新窗口打开 http://127.0.0.1:8600 ，缩放 125%，隐藏书签栏
4. **录屏**：Win+G 打开 Xbox Game Bar → Win+Alt+R 开始/停止（或用 OBS）。建议 1920×1080、60fps、MP4
5. **预演一遍**计时，超 5 分钟就砍 AGH 段的等待画面（剪掉）

## 二、分镜脚本

### 镜头 1 · 开场（0:00–0:20）
画面：停在网页投稿页顶部（报头"研·证"）
> 口播："毕业论文送审通常要等一到两周。我们把高考阅卷制度搬进了 AI：四个评审团十三位 AI 评卷员背靠背独立打分，分差过大自动仲裁，查实作假一票否决——这就是研证，原生运行在 AGH 底座上。"

### 镜头 2 · 真实评卷（0:20–1:30）【要素①②⑤】
操作：
1. 上传 `paper_good.md` → 字数填 10000 → 点"送申评卷"
2. 等待约 1 分钟（这段口播讲机制，别剪掉等待）：
> 口播："十三位评卷员正在并行独立打分——内容审题团四十分、结构逻辑团三十分、语言表达与规范核查各十五分。他们互相看不到对方的分数，模拟高考双评。"
3. 报告出来后**从上往下滚**：总分与等级 → 停在雷达图 2 秒 → 修改优先级路线图 → 展开一位评卷员的扣分明细 → 页尾 token 用量
> 口播："总分 78 通过。每位评卷员的扣分点都给出定位与修改建议，页脚是真实的模型调用成本，完全透明。"

### 镜头 3 · 异常处理：门检打回（1:30–2:10）【要素⑥】
操作：返回投稿页 → 上传 `paper_poor.md`（保持字数 10000）→ 送审 → 打回报告出现
> 口播："不合格的论文呢？门检直接打回：字数不足、查重率超标、缺少必备章节，清单式列明。注意这全程没有调用任何模型——确定性程序把关，零成本零时延。"

### 镜头 4 · 外部能力调用：撤稿核验（2:10–2:45）【要素③】
画面：切到 CMD 窗口
```bat
node packages\cli\bin\yanzheng.mjs 某论文.txt --retractions docs\experiments\实验三撤稿索引.csv --min-words 100 --out 演示.html
```
> 口播："研证还能接入外部数据源：这里加载了 Retraction Watch 撤稿数据库，引用了已撤稿的论文会被自动标记；联网模式下引用逐条到 Crossref 验真、文献到 OpenAlex 检索。"

### 镜头 5 · AGH 闭环（2:45–3:50）【评审 20 分重点】
操作：CMD 运行 `scripts\run-agh-e2e.cmd`，滚动展示输出；如时间允许可切 AGH Web 界面看插件列表
> 口播："最重要的是：研证以 Agnes Harness 为运行底座。这条命令在真实 AGH daemon 里完成全流程——插件安装信任启用、AI 助手在会话中依次调用门检、章节切分、全流程评卷三个工具，其中写报告的调用会弹出权限审批，最后由 AGH 导出原生执行记录——八十四行工具调用事件，可在官方 HTML 里人工核查。全程可复现，一条命令。"

### 镜头 6 · 收尾（3:50–4:10）
画面：回到报告页"研·证"报头
> 口播："九十五项自动化测试、与原实现逐字段等价的金标校验、三个量化实验——研证，让 AI 评卷可信、可查、可回放。开源地址见视频简介。"

## 三、后期与提交

- 剪辑：只剪等待与口误；等待段可 2~4 倍速但保留声音连续
- 加字幕（口播全文），关键数字（78 分 / 84 行 / 141 秒）放大标注
- 导出 MP4 1080p；文件名按提交入口要求（通常含团队名+项目名）
- 上传渠道若限制大小：<500MB 一般无压力

## 四、常见翻车点

- Web 服务窗口别关；录制前 `curl http://127.0.0.1:8600/health` 确认 200
- 演示模式徽标与"真实评卷"徽标二选一，别在视频里混用两种模式还口播"真实"
- CMD 字体调大（属性→字体 16~20），否则命令看不清
- paper_poor.md 打回页面要等约 2 秒才渲染（门检是同步计算），别提前切走
- AGH 段若 daemon 没起：先跑 `scripts\run-agh-e2e.cmd` 确认全绿再录
