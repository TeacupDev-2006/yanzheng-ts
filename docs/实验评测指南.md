# 实验评测指南

> 三个可复现实验，构成"验证严谨性"维度的实验证据链。框架在 `packages/eval`（@yanzheng/eval），
> 产品化改进已反哺引擎（混合查重默认启用、引用撤稿标记）。

## 实验① 评分对照（OpenReview）

**目的**：用真实"论文-人类评分"配对验证 AI 评分与人类评分的排名/分布一致性。

```bash
# mock 冒烟（零成本，验证管线）
node packages/eval/bin/yanzheng-eval.mjs score-compare --venue "ICLR.cc/2023/Conference" --limit 3
# 真实评卷（每样本约 1~3 万 tokens，先小量试跑）
set YANZHENG_API_KEY=sk-你的key
node packages/eval/bin/yanzheng-eval.mjs score-compare --limit 20 --real --out docs/experiments/实验一对照.json
```

- 指标：Spearman 秩相关 + 分布重合度（10 桶交集）
- **声称边界**：结论表述为"排名/分布一致性"，不得表述为"AI 评分被证明正确"（人类评分非真值，跨年分布漂移）；当前为摘要级对照（论文全文对照需接 PDF 全文拉取，留作扩展）
- 已知状态：框架与解析经 mock 测试验证；OpenReview 拉取在本机一次返回 0 样本（venueid 参数或网络待排查，建议换 `ICLR.cc/2024/Conference` 或加代理重试）

## 实验② 查重召回曲线（已实跑 ✅）

**目的**：量化查重在各级改写下的召回，为"是否启用词袋混合相似度"提供数据依据。

```bash
node packages/eval/bin/yanzheng-eval.mjs recall-curve --seed 42 --out docs/experiments/实验二召回曲线.json
```

**实测结果**（testdata 语料，seed=42，阈值 0.5）：

| 混淆等级 | n-gram 召回 | 混合召回(0.5) | 混合召回(0.7) |
|---|---|---|---|
| verbatim | 100% | 100% | 100% |
| light（句序打乱） | 100% | 100% | 100% |
| medium（同义替换） | 50% | 50% | **100%** |
| heavy（替换+乱序+删句20%） | 50% | 50% | **100%** |

**产品化决策（已实施）**：评卷流水线默认启用词袋混合、权重 0.7——中/重度改写召回从 50% 提升到 100%，逐字路径不受影响，金标等价测试不变。混淆生成器（verbatim/light/medium/heavy 四级，确定性 seed）可扩展到真实语料。

## 实验③ 撤稿引用标记（已实跑 ✅）

**目的**：引用了已撤稿文献应被标记（Retraction Watch 开放数据，需遵守其使用条款）。

```bash
node packages/eval/bin/yanzheng-eval.mjs retraction-check --refs docs/experiments/实验三引用清单.txt --csv docs/experiments/实验三撤稿索引.csv
# 接入正式数据：到 retractionwatch.com 接受条款后下载全量 CSV，替换 fixture 即可
```

**实测结果**（4 条引用 fixture）：DOI 精确命中 + 标题模糊命中各 1，误报 0。**产品化决策（已实施）**：`runCitationCheck` 新增 `retractions` 参数与 `retracted/retraction_reason` 明细字段，撤稿引用的证据自动带 `[已撤稿]` 前缀进入评卷。

## 框架结构

```
packages/eval/src/
  obfuscate.ts      可控混淆生成器（四级，LCG 确定性 seed）
  recall.ts         召回曲线计算 + markdown 渲染
  openreview.ts     OpenReview v2 API 客户端（提交+官方评审拉取）
  score-compare.ts  Spearman/分布重合 + 报告渲染
  retraction-eval.ts 撤稿标记评测
  cli.ts            三实验 CLI
```

新增实验的惯例：构造**已知真值**的样本（混淆变体/撤稿 CSV/人类评分配对），指标只声称真值能支撑的强度。
