# 开源论文与评审资源地图

> 用途：为研证的下一步验证（真实语料检出率量化、查重校准、评分对照）提供开放数据源。
> 原则：仅收录确认开放/可申请的资源；**语料只作本地测试，勿再分发入库**（注意各数据集许可）。

## A. 真实论文全文（替代"注入式样本"的评审对象）

| 资源 | 内容 | 对研证的用法 |
|---|---|---|
| [arXiv](https://arxiv.org) + API | 数百万开放论文（PDF/LaTeX/源码），STEM 为主 | 抽取真实论文跑全流程；对照其公开的版本迭代找"前后不一致" |
| [PubMed Central OA](https://www.ncbi.nlm.nih.gov/pmc/tools/openftlist/) | 生物医学全文开放集，可批量下载 | 大规模真实语料测试；PDF 抽取链路压力测试 |
| [CORE](https://core.ac.uk) | 全球机构库开放论文聚合，有 API 与批量数据集 | 中文外论文的规模来源 |
| [OpenAlex](https://openalex.org) | 开放学术元数据（项目已接入检索） | 按主题/年份筛选测试论文清单 |
| 百度学术 / 爱道思（idtust）等中文免费硕博论文库 | 中文硕博论文全文 | **中文毕业论文场景**最贴近的测试对象（注意站点稳定性，仅本地测试） |

> 现实约束：国内本科毕业论文本身不公开（知网不对个人开放批量下载），最接近的替代是**中文硕博论文**（结构相同、篇幅更长）。

## B. 抄袭检测语料（校准 `--corpus` 查重与分块匹配）

| 资源 | 内容 | 对研证的用法 |
|---|---|---|
| [PAN@CLEF 抄袭检测语料](https://pan.webis.de)（PAN-PC 系列） | 英文经典基准：真实源文本 + 自动生成的**多级混淆抄袭**（逐字/改写/翻译） | 量化 n-gram 分块查重在各级混淆下的召回——直接回应可行性判断里"对深度改写不敏感"的短板；为启用嵌入混合相似度提供依据 |
| [HaCoiD（CCL2023 中文学术文本抄袭检测）](https://ccl2023.org) | 中文摘要级抄袭检测数据集，模型生成仿写 | **中文场景**查重校准的首选；论文摘要正是研证评审重点段落 |
| 自建对照：testdata/corpus 现有 2 篇语料 | 项目内置 | 用 A 类真实论文 + PAN 的混淆生成思路，扩充自建中文语料集 |

## C. 同行评审数据集（给"打分"找人类对照）

| 资源 | 内容 | 对研证的用法 |
|---|---|---|
| [PeerRead](https://github.com/allenai/peerreadd)（AllenAI） | AI 顶会论文 + 人类评审意见与评分 | 经典基线：研证四团分数 vs 历史人类评分分布做相关性对照 |
| [NLPeer](https://github.com/allenai/nlpeer) | 多评审数据集统一格式（含 F1000Research 等） | 更大规模的人类评分对照 |
| [OpenReview API](https://docs.openreview.net) | ICLR/NeurIM 等公开评审：论文全文 + 评分 + 评审文本，可编程获取 | **最大规模**的真实"论文-评分"配对源；也可抽取人类评审文本做 persona 参考 |
| F1000Research 开放评审 | 公开姓名的开放式评审 | 观察"可信评审"的行文与证据引用方式 |

## D. 学术诚信/作假检测（校准作假审查与引用验真）

| 资源 | 内容 | 对研证的用法 |
|---|---|---|
| [Retraction Watch Database](https://retractionwatch.com)（与 Crossref 合作开放） | 数万条论文撤稿记录及原因（含数据造假、抄袭） | 引用验真增强：引用了已撤稿论文应被标记；撤稿原因分布可做作假类型先验 |
| [SciFact](https://github.com/allenai/scifact) | 科学主张-证据核实数据集 | 数据一致性技能的校准参照 |
| [SciCite](https://github.com/allenai/scicite) | 引用上下文分类（背景/对比/结果使用） | 引用规范评卷员的细粒度参考 |

## 建议的落地顺序（投入产出比排序）

1. **OpenReview/PeerRead 对照实验**（无需新标注）：抽 20~50 篇带人类评分的真实论文跑研证，对比分数分布与扣分点重合度——直接把可行性判断里"真实语料检出率待量化"推进一格；
2. **HaCoiD/PAN 查重校准**：按混淆等级测召回曲线，决定是否默认启用嵌入混合相似度；
3. **Retraction Watch 接入**：`citation_check` 增加撤稿标记（一条 API/离线 CSV 即可，工程量小、答辩亮点大）；
4. PMC/arXiv 真实论文回归：PDF 抽取链路的鲁棒性压测。

> 提醒：以上数据集多数研究可用、禁止再分发；放入 `testdata/` 前先查各自 LICENSE，仓库里只放"下载脚本 + 抽样说明"。
